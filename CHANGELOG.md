# Changelog
All notable changes to this project are documented in this file.  
Releases following [Semantic Versioning](https://semver.org/spec/v2.0.0.html) specification.  

## 1.0.0
Initial release.

- Browse directories in the terminal and jump to one with a shell function, for example `lk`
- Filter the list by typing, with a fuzzy search
- Move with the arrow keys, select with `Enter`, cancel with `Esc` or `Ctrl+C`
- Shell setup for Bash, Zsh and Fish
- Binaries for macOS and Linux plus an installation script
